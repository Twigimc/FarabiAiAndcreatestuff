# نظام استمارة المشاريع الإبداعية - جامعة الفارابي

هذا المشروع عبارة عن نظام متكامل لاستقبال وإدارة مقترحات المشاريع الإبداعية المعتمدة على الذكاء الاصطناعي لجامعة الفارابي. يتكون النظام من واجهة أمامية (استمارة التقديم) ولوحة تحكم إدارية (Dashboard) لعرض وتصدير البيانات، معتمدًا على لغة PHP وقاعدة بيانات MySQL.

## 🌟 المميزات الأساسية

- **استمارة التقديم (`index.php`)**: واجهة مستخدم حديثة ومتجاوبة، تتيح للأقسام إرسال مقترحات المشاريع.
- **لوحة التحكم (`dashboard.php`)**: واجهة إدارية آمنة لعرض جميع الاستمارات المُقدمة في جدول منظم.
- **تصدير إلى Excel**: إمكانية تصدير جميع البيانات إلى ملف CSV متوافق مع Excel ويدعم اللغة العربية (UTF-8 BOM).
- **تصدير إلى PDF**: إمكانية تحويل الجدول إلى ملف PDF عالي الدقة مباشرة من المتصفح باستخدام مكتبة `html2pdf.js`.

## 🛠️ المتطلبات التقنية

- سيرفر محلي (مثل WAMP أو XAMPP).
- إصدار PHP 7.4 أو أحدث.
- خادم قواعد بيانات MySQL.

## 🚀 طريقة التثبيت والإعداد

1. **نقل الملفات**: قم بوضع مجلد المشروع داخل المجلد الجذري للسيرفر المحلي (مثل `C:\wamp64\www\`).
2. **إعداد قاعدة البيانات**:
   - افتح المتصفح وانتقل إلى الرابط التالي لتشغيل سكربت الإعداد التلقائي:
     `http://localhost/FarabiAiAndcreatestuff/setup_db.php`
   - سيقوم هذا السكربت بإنشاء قاعدة بيانات باسم `farabi_projects` وإنشاء جدول `submissions` بجميع الحقول المطلوبة تلقائياً.
3. **تكوين الاتصال (اختياري)**:
   - بشكل افتراضي، النظام يستخدم اسم المستخدم `root` وبدون كلمة مرور للاتصال بـ MySQL. إذا كانت إعدادات الخادم لديك مختلفة، يمكنك تعديلها في ملف `db.php`.

## 📁 هيكلية الملفات

- `index.php`: الواجهة الرئيسية للتقديم (الاستمارة).
- `submit.php`: واجهة برمجية (API) تستقبل البيانات من الاستمارة وتقوم بحفظها في قاعدة البيانات.
- `dashboard.php`: لوحة التحكم لعرض الاستمارات وإدارتها.
- `export_excel.php`: سكربت مسؤول عن توليد ملف Excel (CSV) وتنزيله.
- `setup_db.php`: سكربت لمرة واحدة لإعداد وإنشاء قاعدة البيانات والجداول.
- `db.php`: ملف يحتوي على إعدادات الاتصال بقاعدة البيانات لتوحيدها في جميع الصفحات.
