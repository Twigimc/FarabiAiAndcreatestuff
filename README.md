# نظام استمارة المشاريع الإبداعية - جامعة الفارابي

هذا المشروع عبارة عن نظام متكامل لاستقبال وإدارة مقترحات المشاريع الإبداعية المعتمدة على الذكاء الاصطناعي لجامعة الفارابي. يتكون النظام من واجهة أمامية (استمارة التقديم) ولوحة تحكم إدارية (Dashboard) لعرض وتصدير البيانات، معتمدًا على لغة PHP وقاعدة بيانات MySQL.

## 🌟 المميزات الأساسية

- **استمارة التقديم (`index.php`)**: واجهة مستخدم حديثة ومتجاوبة، تتيح للأقسام إرسال مقترحات المشاريع، مزودة بحماية ضد هجمات CSRF.
- **لوحة التحكم (`dashboard.php`)**: واجهة إدارية آمنة بتصميم "البطاقات" (Card Layout) لعرض جميع تفاصيل الاستمارات المُقدمة بشكل أنيق.
- **تسجيل الدخول والحماية**: نظام تسجيل دخول للمسؤولين (`login.php`) مع حماية من هجمات التخمين (Rate Limiting) بحظر عنوان IP بعد 5 محاولات فاشلة.
- **تصدير إلى Excel (Native)**: إمكانية تصدير جميع البيانات إلى ملف `.xlsx` احترافي باستخدام مكتبة `PhpSpreadsheet`، مع تنسيق كامل ودعم اتجاه النص من اليمين لليسار.
- **تصدير إلى PDF**: إمكانية تحويل لوحة التحكم إلى ملف PDF عالي الدقة وتقسيم تلقائي للصفحات مباشرة من المتصفح باستخدام مكتبة `html2pdf.js`.

## 🛠️ المتطلبات التقنية

- سيرفر إنتاج متوافق (PHP 8.0+).
- خادم قواعد بيانات MySQL.
- أداة مدير الحزم Composer (فقط إذا أردت تثبيت المكتبات مجددًا).

## 🚀 طريقة التثبيت والإعداد للإنتاج (Production)

1. **قاعدة البيانات**:
   - قم باستيراد ملف `database.sql` المرفق إلى خادم MySQL الخاص بك باستخدام phpMyAdmin أو سطر الأوامر. سيقوم هذا الملف بإنشاء قاعدة البيانات `farabi_projects` وكافة الجداول المطلوبة وحساب المسؤول.
2. **تكوين الاتصال**:
   - قم بتعديل ملف `db.php` ليحتوي على اسم المستخدم وكلمة المرور الخاصة بقاعدة بيانات السيرفر الحقيقي (بدلًا من `root`).
3. **نقل الملفات**:
   - ارفع جميع الملفات إلى مجلد الويب في السيرفر الحي. النظام الآن جاهز تماماً للاستخدام.

## 📁 هيكلية الملفات

- `index.php`: الواجهة الرئيسية للتقديم (الاستمارة).
- `submit.php`: واجهة برمجية (API) لاستقبال البيانات.
- `dashboard.php`: لوحة التحكم الإدارية.
- `login.php` / `logout.php`: نظام المصادقة.
- `export_excel.php`: سكربت التصدير باستخدام Composer.
- `database.sql`: ملف النسخة الاحتياطية لقاعدة البيانات الجاهز للاستيراد.
- `db.php`: إعدادات الاتصال بقاعدة البيانات.
